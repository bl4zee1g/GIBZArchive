# Mamdanistan breakout

This is a text-adventure game I wrote for a class of my vocational school for my compsci apprenticeship. I made two versions:

- mamdanistan breakout.lua
- pretty breakout.lua

## Requirements

- Lua (I used v5.5.1 but it should work just fine on both newer aswell as older versions too)
- For pretty breakout: [Gum](https://github.com/charmbracelet/gum) (be sure to check their [Install Instructions](https://github.com/charmbracelet/gum#installation) if you don't already have it installed)

With the requirements installed, run it with

```lua
lua [path to file.lua]
```
