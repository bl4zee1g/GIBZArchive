As a player,
I want to feel as though if I do decide to help the people I come across, that decision gets rewarded.
So that I have an incentive not to just deny everyone help.

As a developer,
I want this project to be written in Lua
So that I can learn and apply some basics in Lua and not have to deal with C# forcing me into OOP.

As a tester,
I want even early versions of the game to handle invalid input gracefully
So that I can focus my testing on the story aspects of the game and verify its logic.

As a player,
I want there to be lots of different possible runs that feel slightly different
So that the game has good replayability.

As a player,
I want the characters in the game to feel somewhat realistic
So that the game is immersive even if there's no graphics.
