# HTML Grundlagen: Übung 3

## Auftrag
Erstellen Sie eine mehrseitige, klar strukturierte Webseite ausschliesslich mit HTML. Die Seite soll den Besucher über ein Thema Ihrer Wahl informieren (z. B. ein Hobby, eine Sportart, eine Serie, eine Spiele-Community, ein Haustier oder eine fiktive Firma).

Nutzen Sie dabei als Ausgangslage Ihre Portraitseite aus Übung 1 und kopieren Sie sie in dieses Verzeichnis. Erstellen Sie für jedes Thema eine Subseite und verlinken Sie sie korrekt (z.B. eine Subseite für Ihr Hobby, eine Subseite für Ihre Lieblingsserie etc.)
