# JS Vertiefung: Übung 4

## Ziel
Bekannte Grundlagen (DOM, Events, Arrays, fetch) mit typischen Web-Mustern verbinden: Formulare, Speichern im Browser und Filtern von Daten.

## Auftrag
Erledigen Sie die Aufgaben im Ordner `uebung4`. Die Aufgabenstellung steht jeweils im JS-File.

## Lernziele
- Formular-Submit mit `preventDefault` und einfacher Validierung
- CSS-Klassen steuern mit `classList` (statt nur Inline-Styles)
- Daten persistent speichern mit `localStorage`
- Listen dynamisch aktualisieren (hinzufügen / entfernen)
- `async`/`await` statt `.then`
- Arrays mit `filter()` auswerten und die UI neu aufbauen
